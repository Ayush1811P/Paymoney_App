Terms & Privacy Policy

1. Clone Application Notice

This application is a PayMoney Clone (educational demonstration project). It is not an actual payment gateway, financial service, or banking system. It does not facilitate any real-world commercial transactions, and we do not promote any kind of real money transfer.

2. No Real Money Involved

All wallet balances, UPI transfers, cashback deals, and bill recharges shown or generated within this application are purely simulated and represent play money only. No actual monetary deposits, withdrawals, or debits are supported or performed by this software.

3. Sensitive Information Warning

To ensure your security and privacy, you are strictly prohibited from using real banking details, real credit/debit card numbers, real passwords, actual UPI PINs, or any sensitive personal data. Please register with mock/simulated inputs only.

4. Browser Storage and Caching

By registering and using this clone, you grant consent for the app to store settings, session logs, and cache data inside your local browser storage and cookie cache for performance enhancement.

5. Device Permissions & Sensor Access

Certain parts of the clone simulate actual device hardware integration. Specifically:

  • Camera Sensor: Accessed dynamically (webcam/camera feed) when using the UPI QR Scan code feature to search for a payee's address.
  • Gallery / File Library: Used when updating your profile picture avatar or when uploading an existing QR code image from your local file storage to resolve a UPI recipient.

These permissions are requested and used locally on your device only as per functional needs, and no data is shared with third parties.
